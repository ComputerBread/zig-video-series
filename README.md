## goal

I want to make a collection of small zig videos, explaining the language, and
everything you need to know about computers to use zig.
Also help people develop the skills to learn by themselves.

Target: anyone who knows how to operate a computer and is interested in low
level programming and Zig!

if a video becomes outdated, I can always remake it!
